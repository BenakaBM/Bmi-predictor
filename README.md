# Bmi-predictor
BMI Calculator

This is a simple Python script to calculate BMI (Body Mass Index) using weight (kg) and height (cm), and classify it based on standard BMI ranges.

How to Run:

Run the script using Python.

Enter your name, weight, and height when prompted.

Get your BMI and health classification.

BMI Formula:
BMI = weight (kg) / (height (m))²

Categories:

<16: Severe Thinness

16–17: Moderate Thinness

17–18.5: Mild Thinness

18.5–25: Normal

25–30: Overweight

30–35: Obese Class I

35–40: Obese Class II

40: Morbidly Obese
